# 🚕 Unitaxi & Turismo - Landing Page Profissional

![Status](https://img.shields.io/badge/Status-Concluído-success)
![Deploy](https://img.shields.io/badge/Deploy-Vercel-black)

Uma landing page moderna, responsiva e focada em conversão para serviços de transporte urbano e turismo receptivo em João Pessoa (PB) e no litoral do Rio Grande do Norte.

🔗 **Acesse o site ao vivo:** [unitaxi-turismo.vercel.app](https://unitaxi-turismo.vercel.app/)

## 🎯 Objetivo do Projeto
Este projeto foi construído para transformar a presença digital de agências de turismo e serviços de táxi. Em vez de um simples "cartão de visitas", o site atua como uma ferramenta de captação de leads, encaminhando orçamentos detalhados e estruturados diretamente para o WhatsApp da central de atendimento.

## 🚀 Funcionalidades
- **Mobile-First:** Interface totalmente otimizada para celulares, considerando que a maioria dos turistas acessa a plataforma durante a viagem ou no aeroporto.
- **Formulário Dinâmico:** Captura dados essenciais (nome, trajeto, data e número de passageiros) e gera uma mensagem formatada para o WhatsApp.
- **Catálogo de Roteiros:** Seção interativa com filtros por região (Paraíba, RN, Rural) detalhando o que está incluso em cada passeio.
- **Alto Contraste e UI Premium:** Identidade visual ajustada para fundos escuros (azul-petróleo), transmitindo segurança e profissionalismo.
- **SEO Local:** Estrutura de tags otimizada para buscas na região do litoral nordestino.

## 💻 Tecnologias e Arquitetura
O desenvolvimento foi guiado por conceitos de *AI-Assisted Development*, utilizando Inteligência Artificial (Claude/Gemini) para acelerar a escrita do código-fonte a partir de uma arquitetura de software e regras de negócios pré-definidas.

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla - sem frameworks pesados para garantir carregamento instantâneo).
- **Hospedagem & CI/CD:** Deploy contínuo configurado via [Vercel](https://vercel.com/), integrado diretamente a este repositório.
- **Versionamento:** Git e GitHub.

## 🛣️ O Diferencial: Código + Vivência Prática
O design e as funcionalidades deste site não foram baseados em suposições. O projeto une o rigor técnico acadêmico do Bacharelado em Ciência da Computação (UFPB) com o conhecimento logístico prático de quem conhece o transporte de passageiros no dia a dia. 

A estrutura de informações valoriza o que realmente importa para o turista: segurança, conforto (veículos adequados, espaço para bagagem) e o profundo conhecimento dos trajetos urbanos e turísticos.
